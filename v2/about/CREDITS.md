# About desktop

The layout follows the personal desktop, movable windows, shortcuts and taskbar of [girlglock.com](https://girlglock.com/), adapted to Windows XP's Luna styling. Desktop implementation and the inline system icons were created for this project.

The social logos are bundled from their official sources. Discord's blurple symbol comes from its [brand assets](https://discord.com/branding), GitHub's black Invertocat comes from its [logo download](https://brand.github.com/GitHub_Logos.zip), and Steam's icon comes from [Steam's favicon](https://store.steampowered.com/favicon.ico). The original logo files are preserved.

`bliss.jpg` is a JPEG conversion of the Windows XP Bliss wallpaper from the [Windows UI assets archive](https://github.com/bartekl1/windows-ui-assets/blob/main/Wallpapers/Windows%20XP/Desktop/Bliss.bmp). The original wallpaper is by Charles O'Rear and distributed with Microsoft Windows XP. The wallpaper is bundled locally.

The CS2 Premier rating comes from the [Leetify Public CS API](https://api-public-docs.cs-prod.leetify.com/). The locally bundled badge is the original `Leetify Badge Black Small.png` from the [official Leetify developer guidelines](https://leetify.com/blog/leetify-api-developer-guidelines/).
